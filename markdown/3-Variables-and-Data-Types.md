# متغیرها و انواع داده در پایتون

در برنامه‌نویسی، معمولاً لازم است اطلاعاتی مانند نام کاربران، قیمت محصولات، تعداد سفارش‌ها یا وضعیت انجام یک کار را ذخیره کنیم و روی آن‌ها عملیات انجام دهیم.

در پایتون، برای نگهداری این اطلاعات از **متغیرها** استفاده می‌کنیم. هر داده نیز نوعی دارد که مشخص می‌کند چه ماهیتی دارد و چه عملیات‌هایی می‌توان روی آن انجام داد.

## ۱. متغیر چیست؟

متغیر نامی است که برای دسترسی به یک مقدار از آن استفاده می‌کنیم.

برای مثال:

```python
name = "Sara"
age = 20
price = 125.5
```

در این برنامه، سه متغیر ساخته‌ایم:

- `name` نام یک شخص را نگه می‌دارد.
- `age` سن او را نگه می‌دارد.
- `price` یک مقدار عددی را نگه می‌دارد.

علامت `=` در پایتون برای **انتساب مقدار به متغیر** استفاده می‌شود. برای مثال، دستور `age = 20` مقدار `20` را به متغیر `age` نسبت می‌دهد.

اکنون می‌توانیم از این متغیرها در بخش‌های مختلف برنامه استفاده کنیم:

```python
name = "Sara"
age = 20

print(name)
print(age)
print(f"{name} is {age} years old.")
```

خروجی:

```text
Sara
20
Sara is 20 years old.
```

استفاده از متغیرها باعث می‌شود به‌جای تکرار مستقیم مقادیر، بتوانیم آن‌ها را با نامی معنادار در برنامه به کار ببریم.

## ۲. تغییر مقدار متغیر

مقدار یک متغیر می‌تواند در طول اجرای برنامه تغییر کند.

```python
score = 10
print(score)

score = 15
print(score)
```

خروجی:

```text
10
15
```

در این مثال، ابتدا مقدار `10` و سپس مقدار `15` در متغیر `score` قرار گرفته است. پس از انتساب دوم، مقدار قبلی دیگر از طریق این نام در دسترس نیست.

می‌توانیم از مقدار فعلی متغیر نیز برای محاسبات بعدی استفاده کنیم:

```python
score = 10
score = score + 5

print(score)
```

خروجی:

```text
15
```

عبارت `score = score + 5` به این معناست که مقدار فعلی `score` را با `5` جمع کن و نتیجه را دوباره در همان متغیر قرار بده.

## ۳. نام‌گذاری متغیرها

انتخاب نام مناسب، خواندن و درک کد را آسان‌تر می‌کند.

برای مثال، این دو متغیر یک نوع اطلاعات را نگه می‌دارند:

```python
p = 250
product_price = 250
```

اما نام `product_price` مشخص‌تر است و خواننده بهتر می‌تواند کاربرد آن را تشخیص دهد.

در پایتون، برای نام‌گذاری متغیرها این نکات را رعایت می‌کنیم:

- نام متغیر می‌تواند شامل حروف، اعداد و علامت زیرخط (`_`) باشد.
- نام متغیر نباید با عدد شروع شود.
- فاصله در نام متغیر مجاز نیست.
- حروف بزرگ و کوچک با یکدیگر تفاوت دارند؛ بنابراین `age` و `Age` دو نام متفاوت‌اند.
- نباید از کلمات رزروشده پایتون، مانند `if` و `for`، به‌عنوان نام متغیر استفاده کنیم.

نمونه‌های مناسب:

```python
user_name = "Ali"
product_price = 250
item_count = 3
```

نمونه‌های نامعتبر:

```python
# Invalid variable names
2name = "Ali"
product price = 250
```

در نام‌گذاری متغیرهایی که از چند کلمه تشکیل شده‌اند، معمولاً از روش `snake_case` استفاده می‌کنیم؛ یعنی کلمات را با زیرخط از هم جدا می‌کنیم.

## ۴. انواع داده در پایتون

متغیرها می‌توانند مقادیر متفاوتی را نگه دارند. پایتون انواع داده متعددی دارد، اما در شروع کار بهتر است با چند نوع پرکاربرد آشنا شویم.

### اعداد صحیح: `int`

برای اعداد صحیح، مانند تعداد محصولات یا سن افراد، از نوع `int` استفاده می‌شود.

```python
age = 25
item_count = 4
temperature = -3
```

این مقادیر عدد صحیح‌اند و بخش اعشاری ندارند.

### اعداد اعشاری: `float`

برای مقادیر عددی اعشاری، مانند قیمت یا اندازه‌گیری‌ها، از نوع `float` استفاده می‌کنیم.

```python
price = 125.5
height = 1.75
temperature = -2.5
```

در پایتون، برای نوشتن بخش اعشاری از نقطه استفاده می‌کنیم، نه ویرگول.

### رشته‌ها: `str`

رشته برای نگهداری متن استفاده می‌شود. متن را می‌توان با کوتیشن تکی یا دوتایی نوشت.

```python
first_name = "Sara"
message = 'Welcome to Python!'
```

هر چیزی که به‌صورت متن تعریف شود، رشته است؛ حتی اگر شامل ارقام باشد:

```python
phone_number = "09123456789"
```

در این مثال، شماره تلفن را به‌صورت رشته نگه داشته‌ایم؛ زیرا قرار نیست با آن محاسبات عددی انجام دهیم و ممکن است صفر ابتدای آن اهمیت داشته باشد.

### مقادیر منطقی: `bool`

نوع `bool` فقط دو مقدار دارد:

- `True` به معنای درست
- `False` به معنای نادرست

برای مثال:

```python
is_logged_in = True
has_permission = False
```

این نوع داده برای نمایش وضعیت‌ها و بررسی شرط‌ها کاربرد دارد.

نکته مهم این است که در پایتون، `True` و `False` باید با حرف اول بزرگ نوشته شوند.

### مقدار تهی: `None`

گاهی می‌خواهیم نشان دهیم که هنوز مقداری برای یک متغیر مشخص نشده است. در چنین مواردی می‌توانیم از `None` استفاده کنیم.

```python
selected_item = None
```

این مقدار با صفر، رشته خالی یا `False` یکسان نیست. معمولاً نشان می‌دهد که در حال حاضر مقداری وجود ندارد یا هنوز انتخابی انجام نشده است.

## ۵. چگونه نوع داده را تشخیص دهیم؟

با استفاده از تابع `type()` می‌توانیم نوع یک مقدار یا متغیر را بررسی کنیم.

```python
age = 25
price = 125.5
name = "Sara"
is_active = True

print(type(age))
print(type(price))
print(type(name))
print(type(is_active))
```

خروجی:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

این روش هنگام یادگیری پایتون و بررسی کدهایی که خودمان یا هوش مصنوعی تولید کرده‌ایم، بسیار کاربردی است.

## ۶. پایتون زبانی با نوع‌دهی پویا است

در پایتون، لازم نیست هنگام تعریف متغیر، نوع آن را به‌صورت جداگانه اعلام کنیم. پایتون نوع داده را از مقدار انتساب‌یافته تشخیص می‌دهد.

برای مثال:

```python
value = 10
print(type(value))

value = "Hello"
print(type(value))
```

خروجی:

```text
<class 'int'>
<class 'str'>
```

در ابتدا، متغیر `value` به یک عدد صحیح اشاره می‌کند و سپس به یک رشته.

به این ویژگی، **نوع‌دهی پویا (Dynamic Typing)** می‌گویند.

البته این موضوع به معنای بی‌اهمیت‌بودن نوع داده نیست. نوع داده همچنان بر عملیات قابل انجام و نتیجه آن‌ها تأثیر می‌گذارد.

## ۷. انجام عملیات روی داده‌ها

نوع داده مشخص می‌کند که چگونه می‌توانیم با یک مقدار کار کنیم.

برای مثال، می‌توانیم اعداد را جمع کنیم:

```python
price = 100
tax = 10

total = price + tax
print(total)
```

خروجی:

```text
110
```

همچنین می‌توانیم رشته‌ها را به یکدیگر متصل کنیم:

```python
first_name = "Sara"
last_name = "Ahmadi"

full_name = first_name + " " + last_name
print(full_name)
```

خروجی:

```text
Sara Ahmadi
```

اما جمع دو رشته با جمع دو عدد یکسان نیست:

```python
print(10 + 5)
print("10" + "5")
```

خروجی:

```text
15
105
```

در مثال اول، دو عدد با هم جمع می‌شوند. در مثال دوم، دو رشته به هم متصل می‌شوند.

این تفاوت اهمیت زیادی دارد؛ زیرا گاهی داده‌ای که ظاهراً عددی به نظر می‌رسد، در واقع از نوع رشته است.

## ۸. تبدیل نوع داده

گاهی لازم است مقداری را از یک نوع به نوع دیگر تبدیل کنیم. برای این کار، پایتون توابعی مانند `int()`، `float()` و `str()` را در اختیار ما قرار می‌دهد.

برای مثال:

```python
age_text = "25"
age = int(age_text)

print(age + 5)
```

خروجی:

```text
30
```

در این مثال، مقدار `"25"` ابتدا یک رشته است. با استفاده از `int()` آن را به عدد صحیح تبدیل کرده‌ایم و سپس توانسته‌ایم محاسبه انجام دهیم.

چند نمونه دیگر:

```python
price_text = "125.5"
price = float(price_text)

number = 42
number_text = str(number)

print(price)
print(number_text)
```

توجه کنید که هر تبدیل لزوماً امکان‌پذیر نیست. برای مثال، تبدیل رشته `"hello"` به عدد صحیح با `int()` خطا ایجاد می‌کند؛ زیرا این متن یک عدد صحیح معتبر نیست.

## ۹. دریافت اطلاعات از کاربر

یکی از کاربردهای متغیرها، نگهداری اطلاعاتی است که هنگام اجرای برنامه از کاربر دریافت می‌شوند.

تابع `input()` برای دریافت ورودی استفاده می‌شود. نکته مهم این است که **خروجی `input()` از نوع رشته (`str`) است**؛ حتی اگر کاربر عدد وارد کند.

```python
age = input("Enter your age: ")

print(type(age))
print(age)
```

اگر کاربر عدد `25` را وارد کند، نوع داده همچنان `str` خواهد بود.

برای انجام محاسبات، باید ورودی را به نوع عددی مناسب تبدیل کنیم:

```python
age = int(input("Enter your age: "))

next_year_age = age + 1

print(f"Next year, you will be {next_year_age}.")
```

اگر کاربر عدد `25` را وارد کند، برنامه نمایش می‌دهد:

```text
Next year, you will be 26.
```

این مثال ترکیبی از دریافت ورودی، تبدیل نوع داده، استفاده از متغیر و نمایش خروجی است.

البته اگر کاربر به‌جای عدد، متنی نامعتبر وارد کند، برنامه با خطا مواجه می‌شود. بررسی و مدیریت ورودی‌های نامعتبر را در مباحث بعدی می‌توانیم دقیق‌تر بررسی کنیم.


## جمع‌بندی

متغیرها راهی برای نگهداری و استفاده مجدد از اطلاعات در برنامه هستند. در پایتون، انواع داده پرکاربرد شامل `int` برای اعداد صحیح، `float` برای اعداد اعشاری، `str` برای متن، `bool` برای مقادیر منطقی و `None` برای نمایش نبود مقدار است.

پایتون نوع متغیرها را به‌صورت پویا تعیین می‌کند، اما همچنان لازم است تفاوت انواع داده و نحوه تبدیل آن‌ها را بشناسیم.

## تمرین

برنامه‌ای بنویسید که نام یک محصول، قیمت آن و تعداد سفارش را دریافت کند و مبلغ کل را نمایش دهد.

راهنمای تمرین:

1. نام محصول را با `input()` دریافت کنید.
2. قیمت و تعداد را دریافت کرده و به نوع عددی مناسب تبدیل کنید.
3. قیمت را در تعداد ضرب کنید.
4. نام محصول، تعداد سفارش و مبلغ کل را نمایش دهید.

**نکته:** قیمت می‌تواند اعشاری باشد، اما تعداد سفارش معمولاً عدد صحیح است.
