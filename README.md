# دوره پایتون با هوش مصنوعی: از ایده تا ساخت نرم‌افزار

به مخزن آموزشی دوره **«پایتون با هوش مصنوعی: از ایده تا ساخت نرم‌افزار»** خوش آمدید.

این مخزن شامل جزوه‌های آموزشی دوره است که با هدف یادگیری مقدماتی برنامه‌نویسی پایتون، آشنایی با مفاهیم مهندسی نرم‌افزار و استفاده از هوش مصنوعی در فرایند توسعه نرم‌افزار تهیه شده‌اند.

در این دوره، از مفاهیم پایه پایتون شروع می‌کنیم و به‌تدریج با ساختارهای داده، توابع، ماژول‌ها، مدیریت فایل‌ها، برنامه‌نویسی شیءگرا و روش‌های استفاده از هوش مصنوعی برای طراحی، کدنویسی و رفع خطا آشنا می‌شویم. در نهایت، با انجام یک پروژه عملی، آموخته‌های خود را به کار می‌گیریم.

هدف دوره تنها یادگیری دستورهای پایتون نیست؛ بلکه یاد می‌گیریم چگونه یک مسئله را به بخش‌های کوچک‌تر تقسیم کنیم، برای آن راه‌حل طراحی کنیم و با کمک ابزارهای مناسب، ایده خود را به یک نرم‌افزار قابل استفاده تبدیل کنیم.

## 📚 قالب‌های جزوه

جزوه‌های آموزشی در دو قالب در دسترس هستند:

- **PDF:** مناسب برای مطالعه، ذخیره‌سازی و چاپ جزوه‌ها.
- **Markdown (`.md`):** مناسب برای مشاهده در محیط‌های توسعه، جست‌وجو در متن و ویرایش محتوا.

محتوای آموزشی این دو قالب برای مطالعه طراحی شده است؛ بنابراین می‌توانید بسته به نیاز خود از نسخه PDF یا Markdown استفاده کنید.

## 📝 مشاهده فایل‌های Markdown در VS Code

از آنجا که محتوای جزوه‌ها فارسی است و شامل متن فارسی، اصطلاحات انگلیسی و قطعه‌کدهای پایتون می‌شود، پیشنهاد می‌کنیم برای مشاهده بهتر فایل‌های Markdown در **Visual Studio Code (VS Code)** از افزونه زیر استفاده کنید:

[**Persian RTL Markdown Preview**](https://marketplace.visualstudio.com/items?itemName=sinatabar.persian-rtl-markdown-preview)

این افزونه نمایش متن فارسی را به‌صورت راست‌به‌چپ بهبود می‌دهد و در عین حال، متن‌های انگلیسی و قطعه‌کدها را به‌صورت چپ‌به‌راست نمایش می‌دهد.

### ۱. نصب افزونه

۱. برنامه VS Code را باز کنید.
۲. از بخش Extensions به قسمت افزونه‌ها بروید.
۳. عبارت `Persian RTL Markdown Preview` را جست‌وجو کنید.
۴. افزونه را نصب کنید.

همچنین می‌توانید از طریق لینک بالا وارد صفحه افزونه در Visual Studio Marketplace شوید.

### ۲. باز کردن جزوه در حالت Preview

پس از نصب افزونه:

۱. فایل موردنظر با پسوند `.md` را در VS Code باز کنید.
۲. کلیدهای `Ctrl + Shift + P` را فشار دهید تا **Command Palette** باز شود.
۳. دستور `Open with Persian RTL Editor` را جست‌وجو و اجرا کنید.
۴. در ویرایشگر بازشده، حالت **Preview** را انتخاب کنید.

در این حالت، جزوه را به‌صورت قالب‌بندی‌شده مشاهده خواهید کرد و خواندن متن‌های فارسی و ترکیب آن‌ها با کدهای انگلیسی آسان‌تر می‌شود.

### ۳. تنظیم Preview به‌عنوان حالت پیش‌فرض

برای اینکه فایل‌ها به‌صورت پیش‌فرض در حالت Preview باز شوند، مراحل زیر را انجام دهید:

۱. وارد تنظیمات VS Code شوید؛ برای مثال، با فشردن `Ctrl + ,`.
۲. عبارت `Persian RTL Editor` را در قسمت جست‌وجوی تنظیمات وارد کنید.
۳. تنظیم مربوط به **Default View Mode** را پیدا کنید.
۴. مقدار آن را روی **Preview** قرار دهید.

از این پس، حالت پیش‌فرض ویرایشگر اختصاصی افزونه روی Preview خواهد بود. هر زمان که لازم باشد می‌توانید به حالت ویرایش یا نمایش هم‌زمان ویرایش و پیش‌نمایش برگردید.

> **نکته:** این تنظیم مربوط به ویرایشگر اختصاصی افزونه است. اگر فایل را در ویرایشگر معمولی VS Code باز کرده‌اید و فقط می‌خواهید پیش‌نمایش Markdown را ببینید، می‌توانید دستور `Markdown: Open Preview` را از Command Palette اجرا کنید. در ویندوز و لینوکس، میان‌بر این دستور `Ctrl + Shift + V` است.

## 🎯 هدف نهایی

این جزوه‌ها همراهی برای یادگیری و تمرین هستند. پیشنهاد می‌کنیم مطالب را به‌ترتیب مطالعه کنید، مثال‌ها را اجرا کنید و برای درک بهتر مفاهیم، آن‌ها را تغییر دهید و آزمایش کنید.

در زمان انجام تمرین‌ها و پروژه‌ها نیز می‌توانید از هوش مصنوعی کمک بگیرید؛ اما به یاد داشته باشید که **درک مسئله، بررسی کد و اطمینان از عملکرد درست برنامه، بخش مهمی از فرایند یادگیری شماست.**

امیدواریم این دوره به شما کمک کند تا با اعتمادبه‌نفس بیشتری از ایده‌پردازی به طراحی و ساخت نرم‌افزار برسید.
